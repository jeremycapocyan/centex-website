# Team profiles

Edit `src/lib/team.ts` to add or update an approved employee profile. Each entry needs a unique slug, name, position, initials, introduction, and biography paragraphs. Add an optimized, authorized headshot under `public/images/` and set the entry's `image` path when available. Omit `image` to show a clearly labeled initials placeholder; do not substitute a generated person.

Profiles automatically appear in the homepage team section, `/team/`, individual `/team/[slug]/` bio pages, and the sitemap. Use verified facts and approved biographies only. Jeremy Angelo Alonzo's full bio and headshot are currently pending.

The commercial auto/vehicle offering retains the existing `commercial-truck` URL and form identifier so saved links continue working; its displayed name and coverage copy have been updated.
